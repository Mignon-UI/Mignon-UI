Frequently Asked Questions

Everything you need to know about Mignon UI and local AI roleplay.

What is Mignon UI?

Mignon UI is a private, offline-first client for local AI roleplay and storytelling. It allows you to create multi-character lobbies, customize aesthetics with retro themes, and maintain long-term memory across sessions.

Is Mignon UI free and private?

Yes, Mignon UI is 100% free, open-source (AGPL-3.0), and offline-first. Your chats, character cards, and API keys are stored locally on your device with zero telemetry.

Which local AI engines are supported?

Mignon UI works out of the box with Ollama, Kobold.cpp, LM Studio, LocalAI, vLLM, and any server exposing an OpenAI-compatible API endpoint.

Can I import Tavern character cards?

Yes! You can drag and drop standard V2 PNG character cards or JSON cards to import characters, personalities, scenarios, and greeting messages automatically.
