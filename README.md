<dl>
  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:layout.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:layout.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Clean UI & Simple Setup</b></dt>
  <dd>Mignon UI is designed to be clean, distraction-free, and simple to navigate. We've pre-configured the heavy lifting behind the scenes (prompt formatting, model settings) so you can get straight to your stories without configuration fatigue.</dd>

  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:users.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:users.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Dynamic Multi-Bot Lobbies</b></dt>
  <dd>Chat with multiple AI characters at the same time. Characters take turns naturally, talking to you and each other based on their personality, context, and proximity without you having to manually prompt each one. (You can also set any character card as your active persona to play <em>as</em> them!)</dd>

  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:book-open.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:book-open.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Tavern Card Imports & Lorebooks</b></dt>
  <dd>Bring your favorite characters with you by importing standard character cards (.png V2 format) and JSON cards instantly. Link world lorebooks to characters or rooms to dynamically trigger world rules and locations.</dd>

  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:brain.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:brain.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Smart Story Memory</b></dt>
  <dd>Keeps long roleplays going without characters forgetting who they are or what happened. Summarizes key events into milestone chapters and uses smart local memory retrieval.</dd>

  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:shield-check.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:shield-check.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Private & Offline-First</b></dt>
  <dd>Your chats, characters, and API keys are stored in a secure local database directly on your device. Zero telemetry, and no cloud dependencies by default. Run completely offline via Ollama or Kobold.cpp, or connect your personal API keys.</dd>

  <dt><picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:palette.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:palette.svg?color=%231e293b" width="16" height="16" alt="" /></picture> <b>Aesthetic Themes</b></dt>
  <dd>Instantly switch between beautiful custom styles like <em>Bubblegum Pop</em>, <em>Neo-Cyber</em>, <em>Dollhouse</em>, <em>Builder</em>, <em>Mignon UI Classic</em>, <em>Dark Yellow</em>, and <em>Sketch Book</em>, with full support for light and dark modes.</dd>
</dl>

## <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:rocket.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:rocket.svg?color=%231e293b" width="20" height="20" alt="" /></picture> Getting Started

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:download.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:download.svg?color=%231e293b" width="18" height="18" alt="" /></picture> Installation

To install Mignon UI, visit the **[Releases](https://github.com/Mignon-UI/Mignon-UI/releases)** page of this repository and download the package for your platform:

#### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/simple-icons:windows11.svg?color=%23f0f6fc"><img src="https://api.iconify.design/simple-icons:windows11.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Windows
* **Installer**: Download the `.exe` installer, run it, and follow the setup wizard.
* **Portable**: Download the `Mignon_UI_windows_portable.zip` archive, extract it, and run `Mignon UI.exe`.
* **Note**: Since the app is newly compiled and unsigned, Windows SmartScreen will show a warning (*"Windows protected your PC"*). Click **"More info"** and then **"Run anyway"** to proceed.

#### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/simple-icons:apple.svg?color=%23f0f6fc"><img src="https://api.iconify.design/simple-icons:apple.svg?color=%231e293b" width="16" height="16" alt="" /></picture> macOS (Universal: Intel & Apple Silicon)
* **Installer**: Download the `.dmg` file, open it, and drag **Mignon UI** to your `Applications` folder.
* **Note (First Launch)**: Since the app is unsigned, macOS Gatekeeper will block it (*"Developer cannot be verified"*). 
  To open it, **right-click** (or hold `Control` and click) the **Mignon UI** icon in your `Applications` folder, select **Open** from the menu, and click **Open** again in the confirmation dialog. You only need to do this once.

#### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/simple-icons:linux.svg?color=%23f0f6fc"><img src="https://api.iconify.design/simple-icons:linux.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Linux
* **Debian / Ubuntu**: Download the `.deb` package and install it via your package manager (`sudo dpkg -i mignon-ui*.deb`).
* **Universal AppImage**: Download the `.AppImage` file, make it executable (`chmod +x Mignon-UI*.AppImage`), and double-click to run.

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:sliders.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:sliders.svg?color=%231e293b" width="18" height="18" alt="" /></picture> Onboarding Setup

When you launch Mignon UI for the first time, our **Onboarding Wizard** will walk you through the setup in under a minute:

1. **Aesthetics**: Pick your favorite theme design and light/dark mode preference.
2. **AI Connection**: Choose your language model source (local or cloud).
3. **Persona Profile**: Define your name, avatar, and background story so the bots know who they are speaking to.

## <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:cpu.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:cpu.svg?color=%231e293b" width="20" height="20" alt="" /></picture> Connecting Your AI Engine

Mignon UI is a frontend client that connects to your choice of local or cloud AI backends. Here is how to configure them:

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/simple-icons:ollama.svg?color=%23f0f6fc"><img src="https://api.iconify.design/simple-icons:ollama.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Local Ollama (Recommended for Beginners)
1. Download and run [Ollama](https://ollama.com/).
2. Run your preferred model in your terminal (e.g., `ollama run llama3`).
3. In Mignon UI, select **Local Ollama** as your provider. The default address is `http://127.0.0.1:11434/v1`.

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:zap.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:zap.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Local Kobold.cpp (Recommended for Low-Spec Gaming Laptops)
Kobold.cpp is highly optimized for systems with limited VRAM (e.g., 6GB VRAM GPUs).
1. Download and run [Kobold.cpp](https://github.com/LostRuins/koboldcpp).
2. For optimal performance, enable **ContextShift** and **SmartCache**, and use **KV Cache Quantization (`q4_0`)** to save up to 1.6GB of VRAM (see our [6GB Laptop Tuning Guide](docs/optimization.md) for step-by-step instructions).
3. In Mignon UI, select **Local Kobold.cpp** as your provider. The default address is `http://127.0.0.1:5001/v1`.

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:cloud.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:cloud.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Cloud OpenRouter
1. Get an API key from [OpenRouter](https://openrouter.ai/).
2. In Mignon UI, select **Cloud OpenRouter** as your provider, paste your API key, and choose your model (e.g., `meta-llama/llama-3.1-8b-instruct:free`).

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:server.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:server.svg?color=%231e293b" width="16" height="16" alt="" /></picture> Custom (OpenAI-Compatible)
Connect to any OpenAI-compatible server (like LM Studio, Groq, DeepSeek, or Gemini). Simply enter your endpoint URL and optional API key.

## <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:terminal.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:terminal.svg?color=%231e293b" width="20" height="20" alt="" /></picture> Developer Setup & Compiling from Source

If you want to run the project in development mode or compile your own installers:

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:check-circle-2.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:check-circle-2.svg?color=%231e293b" width="18" height="18" alt="" /></picture> Prerequisites
Ensure you have the following installed:
* **Bun** (v1.4.0 or higher) *(or Node.js v20+)*
* **Rust / Cargo** (v1.75 or higher)
* **OS Build Tools**:
  * **Windows**: Visual Studio Community Build Tools (with the **Desktop development with C++** workload enabled).
  * **macOS**: Xcode Command Line Tools (`xcode-select --install`).
  * **Linux**: `webkit2gtk-4.1` and build packages (e.g., `build-essential`, `libssl-dev`, `libgtk-3-dev`).

### <picture><source media="(prefers-color-scheme: dark)" srcset="https://api.iconify.design/lucide:play.svg?color=%23f0f6fc"><img src="https://api.iconify.design/lucide:play.svg?color=%231e293b" width="18" height="18" alt="" /></picture> Quick Start (Development Mode)
1. Clone the repository and install dependencies:
   ```bash
   bun install
   ```
2. Launch the developer sandbox:
   ```bash
   bun run tauri:dev
   ```
